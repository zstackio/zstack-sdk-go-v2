## 文件归属

优先使用对应的现有资源文件。操作跨多个资源时，参考请求对象和已有方法的归属。没有对应文件时创建具体资源文件，例如 `ip_address_actions.go` 和 `audit_actions.go`。

`DeleteIpAddress` 与 `QueryIpAddress`、`GetIpAddress`、`PageIpAddress` 同属 IP 地址操作。迁移保留删除方法原有的 `v1/l3-networks` 路径和参数。参数、响应类型和 HTTP 客户端不在本次拆分范围内。

仓库没有提交生成 SDK action 文件的脚本或模板。后续若从外部生成器刷新客户端，生成端应按资源选择目标 `*_actions.go`，可用迁移清单核对已有方法归属。
